# Zone Auction

Статический прототип сайта аукционов Zone Auction.

## Структура проекта

```text
assets/
  css/        — общие стили
  images/     — изображения
  js/         — клиентские скрипты
tempPage/     — прототип главной страницы
```

## Локальный запуск

После добавления главной страницы откройте `tempPage/index.html` в браузере.
Установка зависимостей и сборка не требуются.

Для запуска через локальный HTTP-сервер (при установленном Python):

```sh
python -m http.server 8000
```

Затем перейдите по адресу <http://localhost:8000/tempPage/>.
