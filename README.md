# Zone Auction

Статический прототип мониторинга аукциона STALCRAFT: X. Главная страница
сверстана по экрану «01 · Каталог» из макета `Zone Auction.fig` (вариант Paper).

## Структура проекта

```text
assets/
  css/        — стили, локальный шрифт Manrope и его лицензия
  images/     — исходные векторные иллюстрации из макета
  js/         — поиск, фильтрация по категориям и сортировка
tempPage/     — главная страница каталога
```

## Локальный запуск

Откройте `tempPage/index.html` в браузере.
Установка зависимостей и сборка не требуются.

Для запуска через локальный HTTP-сервер (при установленном Python):

```sh
python -m http.server 8000
```

Затем перейдите по адресу <http://localhost:8000/tempPage/>.

## Содержимое прототипа

Шесть предметов, названия, цены и количество лотов перенесены из макета.
Поиск, категории и сортировка работают локально. Данные демонстрационные,
подключение к API и переходы на отдельные страницы лотов пока не реализованы.
Шрифт и иллюстрации хранятся в проекте, внешние сервисы для просмотра не нужны.

## Оформление и адаптивность

Стили подключены из `assets/css/main.css`; встроенных CSS-стилей в HTML нет.
Цвета вынесены в CSS-переменные, используется локальный шрифт Manrope.
Шапка, поиск, категории и панель результатов используют Flexbox, строки
каталога — CSS Grid. Ширина контента ограничена, остальные блоки подстраиваются
под доступное пространство.

Media queries на `56rem` и `40rem` меняют расположение данных в строках,
панель результатов и оформление для телефона. Категории переносятся на новые
строки; до `30rem` поиск и кнопка располагаются друг под другом.
Для клавиатурной навигации предусмотрены видимый фокус и ссылка
«Перейти к содержимому». Семантические элементы HTML сохранены.
