# Журнал AI-работ Zone Auction

Журнал дополняется в следующих задачах: запрос, фактические изменения, проверки,
обнаруженные проблемы, исправления и непроверенные пункты.

## 2026-10-21 — запускаемая основа лабораторной №6

### Задача и согласование

Реализовать только основу по согласованной подготовке, сохранив оформление и
прошлую работу, с последующим получением данных через backend. После появления
`MVP_PREPARATION.md` пользователь явно разрешил реализацию. Получение лотов
в эту задачу не входит. Объём зафиксирован в `mvp-scope.md`.

- Внутренний репозиторий `project/zone_auction`, исходный HEAD `2ca7227`.
- Отслеживаемые файлы чистые. Пользовательские неотслеживаемые файлы:
  `MVP_PREPARATION.md` и два DOCX с ТЗ/бэклогом; сохранены, в коммит этой задачи

### Фактические изменения

- `frontend/`: React + TypeScript + Vite + Router, npm lock-файл.
- Переиспользованы `assets/css/main.css`, локальный Manrope и `device.svg`;
  дополнительные стили находятся в `frontend/src/app.css`.
- Главная сохраняет композицию шапки, вступления, поиска, категорий, каталога
  и подвала. Шесть демонстрационных строк в активный интерфейс не перенесены.
  Вместо них показано начальное состояние; неподключённые элементы отключены.
- Маршруты будущих лотов/подробностей, неизвестного адреса и возврат в каталог.
- `frontend/src/api.ts`: типизированный запрос относительного `/api/health`,
  проверка ответа. На главной загрузка/успех/ошибка и ручной повтор.
- `backend/`: минимальный .NET 10 Web API, health, серверные настройки интеграции,
  локальный пример без реквизитов. Нет OAuth, запросов лотов, БД или аккаунтов.
- Vite proxy и доступ только к frontend и общим assets, без разрешения раздавать
  всё дерево backend через файловый сервер Vite.
- Дополнен `.gitignore`, обновлён README и созданы документы объёма/журнала.
  `tempPage/` и исходные `assets/` не изменены.

### Проблемы и исправления

- Winget нашёл Node.js LTS, но установка MSI не завершилась за 240 секунд.
  Для проверок использованы Node 24.20.0 и npm 11.13.0 из временного каталога
  вне репозитория. Повторяемый запуск в README требует обычной установки Node LTS.
- У временно распакованного npm не работал вложенный вызов `npm run` через PATH.
  Скрипт build непосредственно вызывает `tsc --noEmit && vite build`.
- Локальный IPv6 `::1:5173` в окружении отклонял подключения; Vite переведён на
  `127.0.0.1`. Порт фиксирован, при занятости Vite не меняет его молча.
- При первом браузерном прогоне шрифт из внешнего относительно frontend
  каталога получил 403 от Vite. Явно разрешены только frontend и assets;
  повторная проверка подтвердила загрузку Manrope.
- Первая попытка `npm ci` при работающем Vite получила Windows EPERM на
  занятом `esbuild.exe`. Проверочный Vite остановлен; повторный `npm ci` успешен.

### Выполненные проверки

- `dotnet build backend/ZoneAuction.Api.csproj`: успешно, 0 ошибок/предупреждений.
- Backend запущен вместе с Vite; прямой `/api/health` на 5080 и проксированный
  на 5173 возвращают HTTP 200 и `{"status":"ok"}`.
- `npm ci`: установка из lock-файла успешна, npm audit сообщает 0 уязвимостей.
  `npm run typecheck` и `npm run build`: обе команды успешны.
- Chromium через временный Playwright вне репозитория: главная на 360, 768,
  1440 px; горизонтального переполнения нет, CSS применён, локальный Manrope
  действительно загружен, изображение имеет ненулевой naturalWidth.
- Скриншоты узкого и широкого экранов просмотрены; композиция пригодна для
  указанных размеров. Поиск/категории явно отключены.
- Прямые переходы на обе страницы будущих лотов и неизвестный маршрут;
  возврат в каталог; первая Tab-навигация открывает skip-link.
- Принудительный HTTP 503 health в браузере → сообщение о недоступности;
  ручной повтор после восстановления → успешное состояние.
- Production-сборка открыта через Vite preview, Manrope и иллюстрация загружены.
  Preview не использовался для проверки API: proxy предназначен для dev.
- При успешном совместном запуске нет необработанных ошибок JS или HTTP-ошибок
  загрузки ресурсов. Ошибка 503 отдельно введена намеренно для проверки.
- `git check-ignore` подтверждает исключение локального JSON, bin, node_modules
  и dist. `git diff --cached --check` проходит; staged diff просмотрен.
- Production-сборка выполнена с искусственной контрольной строкой в
  `Stalcraft__ClientSecret`: строка отсутствует в dist. В клиентской сборке
  нет ключей серверных реквизитов и OAuth-адреса. В staged diff не обнаружены
  секреты; JSON-пример содержит пустые ID/секрет. Настоящие реквизиты не вводились.
- Запрос к backend/appsettings.json через `/@fs/` Vite возвращает 403 без
  содержимого конфигурации. Повторный запрос health через dev proxy успешен.
- `git diff --name-only -- tempPage assets` пуст: прежняя работа сохранена.

### Непроверенное / вне объёма

- Настоящая OAuth-авторизация и production-лоты, состояние 429 внешнего API.
- Firefox, Safari, реальные мобильные устройства и экранный диктор.
- Полный клавиатурный сценарий будущего поиска/лотов (они ещё не реализованы).
- Production-размещение и маршрутизация на отдельном хостинге.
